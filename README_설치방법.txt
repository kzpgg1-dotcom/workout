Workout Intelligence V2.1.3 — Offline PWA Edition
================================================

1. 기존 운동기록 백업 (반드시 먼저)
   기존 앱에서 내보내기 > JSON으로 내보내기 실행.
   원본 HTML과 백업 파일을 별도 보관합니다.

2. 배포
   이 ZIP을 풀고, 기존 앱이 있는 HTTPS 웹사이트의 같은 폴더에 아래 파일들을 업로드합니다.
   index.html, index1.html, sw.js, manifest.json, icon-192.png, icon-512.png,
   icon-maskable-512.png, apple-touch-icon.png
   index1.html은 기존 URL이 index1.html인 경우에도 사용할 수 있는 동일한 앱입니다.
   기존 진입 파일명이 Workout_Intelligence_V2.html이었다면 index.html 복사본을 그 이름으로도
   올리세요. 기존 사이트의 다른 파일/앱을 덮어쓰지 않도록 확인합니다.
   GitHub Pages: 기존 배포 브랜치/폴더에 파일을 함께 커밋하고 배포 완료 후 접속.
   Netlify / Cloudflare Pages: 기존 사이트의 기존 배포 폴더/프로젝트를 업데이트.
   새 사이트나 새 도메인을 만들 필요는 없습니다. 기존 URL을 유지하는 것이 좋습니다.
   HTTPS 또는 개발용 localhost 필요. file://로 HTML만 열면 PWA 등록 불가.

3. iPhone 홈 화면
   Safari에서 기존 앱 URL을 온라인 상태로 열고 홈 또는 설정에
   '오프라인 실행 준비 완료'가 표시될 때까지 기다립니다.
   Safari 공유 메뉴 > 홈 화면에 추가. 기존 홈 화면 아이콘이 이미 있다면 먼저 기존 아이콘에서
   업데이트를 확인하세요. 삭제/재설치 전에 반드시 JSON 백업을 확인합니다.
   홈 화면 아이콘에서 온라인 상태로 한 번 앱을 열고 준비 완료 표시를 다시 확인합니다.
   iOS 버전/설정에 따라 Safari와 홈 화면 앱의 저장 영역이 다를 수 있습니다.

4. 오프라인 시험
   앱을 닫고 비행기 모드를 켠 뒤 Wi-Fi도 꺼져 있는지 확인합니다.
   홈 화면 아이콘으로 다시 실행합니다. '오프라인 모드' 표시와 기존 기록을 확인합니다.
   테스트 기록을 수정한 뒤 다시 종료/실행하여 저장되는지 확인합니다.
   실제 iPhone에서 위 절차를 확인하기 전까지는 기존 앱과 백업을 유지하세요.

5. 데이터 유지
   V2.0의 wj4 / wj4_profile / wj4_body 키와 기존 기록 구조를 그대로 사용합니다.
   같은 origin(프로토콜, 호스트, 포트) 및 저장 영역에서는 기존 데이터가 유지됩니다.
   새 도메인이나 브라우저, 별도 홈 화면 저장 영역에서는 데이터가 보이지 않을 수 있으므로
   기존 JSON 백업을 가져오기 > JSON 파일 불러오기로 복원합니다.
   서비스 워커는 앱 파일만 캐싱하며 운동기록 자체를 변경하거나 클라우드에 보내지 않습니다.
   브라우저의 웹사이트 데이터 삭제, 저장 공간 부족, 기기 정책에 의해 캐시/운동기록이
   제거될 수 있습니다. 정기적으로 JSON 백업하세요.

6. 업데이트
   홈/설정의 '업데이트 확인'을 사용합니다. 새 버전이 준비되면 '업데이트 적용'을 눌러
   새로고침합니다. 운동 입력을 먼저 저장합니다. 다음 배포 시 sw.js의 VERSION도 변경해야
   새 캐시가 설치됩니다. 모든 파일을 함께 배포하세요.
   캐시가 사라졌다면 온라인에서 '캐시 복구'를 시도합니다. 웹사이트 데이터를 삭제하지 마세요.

7. 검증 범위
   기존 앱의 JavaScript 본문과 저장 키 보존 확인, JS 구문 검사, manifest/아이콘 검증,
   Node 모의 Service Worker 환경에서 설치/캐시/오프라인 URL 응답/업데이트 메시지 검증.
   실행 환경의 브라우저 정책이 로컬 웹서버 접속을 차단하여 실제 브라우저 종단간 시험은
   완료하지 못했습니다. iPhone Safari/홈 화면 실행은 배포 후 확인해야 합니다.
   새 기능: 오프라인 앱 파일 캐시, 홈 화면 아이콘/manifest, 준비 상태, 업데이트 확인 및 적용.
   클라우드 동기화 및 Apple Health 연동은 포함하지 않습니다.

8. V2.1.1 수정
   모바일 입력창 글자 크기 16px 이상으로 조정하여 iOS 자동 확대 방지 (수동 확대 유지).
   메모 가져오기 기본값은 미완료 루틴. 이미 수행한 과거 운동은 완료 기록 옵션 선택.
   기존 기록은 변경하지 않습니다. 잘못 완료된 날짜는 ··· > 이 날 완료 체크 초기화.
   기존 완료 날짜에 미완료 루틴을 가져오는 경우 해당 날짜는 보호합니다.
   실제 iPhone Safari 입력 시 자동 확대 방지는 배포 후 확인이 필요합니다.
